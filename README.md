# dsh-content-cleaner · 会话缓存清理

DSH-Go 手机 App 的原生插件：在这个 App 里列会话、删会话、清缓存。全程在本机磁盘上操作，不联网。

> 面向 **dsh-go 手机原生界面**（Flutter）。它不是 Harness 网页版插件：没有 `client.js`、不注册任何 HTTP 路由、不写 `platform` 字段。

## 一、它是什么

装好之后，App 里多一个入口「会话缓存清理」，里面是一块面板，三部分：

| 块 | 内容 |
|---|---|
| **概览** | 会话总数、合计占用、可删条数、项目目录数，全部实时扫盘得出 |
| **会话** | 一行一个会话：标题 · 相对时间 · 体积；可删的点一下即勾选，运行中与本对话置灰不可选 |
| **缓存** | 两类缓存各一行，显示体积与文件数，行内点一下就能清空 |

## 二、与老插件 `dsh-session-cleaner` 的关系

老插件只能在**网页版**用：它在服务端注册一条 `POST /api-ext/session.delete` 路由，客户端往里塞一段网页 DOM 菜单。手机 App 是 Flutter 原生界面，既不会去请求那条路由，也没有那段 DOM，所以老插件在手机上点了没反应。

本插件是**手机原生版**：

- 删会话的思路沿用老插件验证过的顺序（拒删运行中 → 停空闲 agent → 从内存 live store 摘除 → 删磁盘），但不走 HTTP，改成面板里点按触发；
- 补上了老插件漏掉的清理：删会话时一起清掉 `storages/session_projcache` 里的投影缓存、并从工作区登记里摘掉该会话，避免列表里留「幽灵行」；
- 两者**互不干扰，可以同时装**：网页端继续用 `dsh-session-cleaner`，手机端用本插件。

## 三、安装

```sh
dsh plugin --profile web add /path/to/dsh-content-cleaner
```

装的是指向该目录的链接，所以**目录不能删**。

> **重要**：`package.json` 的改动会被自动重读；`lib/` 里的代码改动**必须**到 App 的「引擎」页重启一次引擎才生效。

## 四、在哪看到它

- 「全部功能」列表里 → 「会话缓存清理」
- 对话详情页 → 「插件」页签 → 「会话缓存清理」

打开后：概览显示会话总数（可清理会话口径，不含引擎自用的生命周期目录），会话块列出每个会话的标题、多久没动、占多大。

## 五、会删什么 / 不会删什么

**会删**（都要你亲手点确认）：

| 目标 | 说明 |
|---|---|
| `sessions/<项目目录>/<会话 id>/` | 勾选某个会话并确认后，整个会话目录被删除 |
| `storages/session_projcache/sessions/<会话 id>.json` | 该会话的标题与投影缓存，跟着一起清，否则列表留幽灵行 |
| `storages/workspace.json` 里该会话的登记 | 从工作区名单、归档名单、置顶名单里摘掉（改前会备份 `workspace.json.bak`） |
| `cache/` 里的内容 | 桥接与临时文件，清空后目录保留、会自己重生 |
| `storages/session_projcache/sessions/` 里的内容 | 会话标题投影缓存，清空后标题可能暂时显示 `(无标题)`，重新打开会话或重启引擎会重建 |

**不会删**：

- `storages/cost-meter/` —— 计费台账，删了统计从零开始；
- `speech-to-text/` —— 语音识别模型，删了要重新下载；
- `sessions/.dsh-go-lifecycle/` —— 引擎自用的锁与删除墓碑，动了会让引擎状态异常；
- **正在运行的会话**（有 agent 在跑）；
- **当前正在聊的这个对话**。

代码里有显式黑名单与白名单：清理目标只认上面这两个缓存目录，路径里出现 `cost-meter` 或 `speech-to-text` 直接拒绝；删除只发生在 `sessions/` 下本项目扫描到的会话目录。

## 六、风险警示（请先读完再点）

- **删除不可恢复**：没有回收站、没有撤销、没有二次备份。确认弹窗里会写明「将删除 N 个会话，共 X MB」，看完再点。
- **批量删除**：可以「全选可删」，一次清掉所有能删的会话；这一步同样只有一次确认机会。
- 删会话不会动其余会话，也不影响你的模型、密钥、设置与工作区文件本身。
- 清空投影缓存后，会话列表的标题会短暂变成 `(无标题)`，这是预期行为。

## 七、卸载

```sh
dsh plugin --profile web remove dsh-content-cleaner
```

然后把本仓库目录删掉即可。卸载不会删除任何会话或缓存数据。

## 八、自检

```sh
node scripts/selftest.mjs        # 造临时环境跑通全流程，末尾打印「全部通过」
node scripts/privacy-scan.mjs    # 开源前隐私扫描，block 级命中必须为 0
node scripts/make-test-session.mjs '测试会话'   # 造一个可安全删除的测试会话
```
